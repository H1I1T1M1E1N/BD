Задание 1. Анализ эффективности вакансий и конверсии откликов

Для каждой вакансии необходимо проанализировать эффективность подбора кандидатов. Рассматривать все опубликованные версии вакансий, включая архивные. Отклики должны учитываться по тем версиям вакансий, на которые они были первоначально отправлены.

Для каждой вакансии предварительно определить количество полученных откликов, количество уникальных соискателей, количество откликов, достигших этапа просмотра, интервью и предложения о работе, а также количество принятых предложений. Если отклик несколько раз проходил один и тот же этап, учитывать его при подсчёте достигших этапа только один раз.

На основе этих данных рассчитать по каждой вакансии:
- общее количество откликов
- количество уникальных кандидатов
- конверсию из отклика в просмотр
- конверсию из просмотра в интервью
- конверсию из интервью в предложение
- конверсию из предложения в принятие
- общую конверсию из отклика в принятое предложение
- среднее время от получения отклика до первого просмотра
- количество отказов
- процент отказов от общего количества откликов

Конверсию рассчитывать как отношение количества откликов, достигших следующего этапа, к количеству откликов, достигших предыдущего этапа, умноженное на 100. При отсутствии данных для расчёта конверсия должна принимать значение NULL.

В итоговый результат включать только вакансии, для которых одновременно выполняются условия: количество откликов не менее 10 и количество проведённых интервью не менее 3.

Результат отсортировать по общей конверсии в принятое предложение по убыванию, затем по количеству откликов по убыванию.

Задание 2. Выявление проблемных откликов и нарушений сроков обработки

Найти отклики, для которых обнаружены нарушения сроков обработки или проблемы в истории прохождения этапов подбора. Рассматривать только отклики, имеющие хотя бы одну запись прохождения этапа.

Для каждого отклика необходимо проанализировать все связанные этапы и определить количество зарегистрированных этапов, время первого и последнего перехода, текущий этап, ответственного рекрутера, установленный срок завершения и фактическое время нахождения на текущем этапе. Дополнительно определить количество повторных прохождений этапов и количество просроченных этапов.

Отклик считать проблемным, если выполняется хотя бы одно условие:
- текущий этап не завершён, но установленный срок уже истёк
- у активного этапа отсутствует ответственный рекрутер
- одновременно существуют несколько незавершённых этапов
- время завершения какого-либо этапа меньше времени его начала

Для каждой найденной записи определить текстовый тип основной проблемы:
- превышен срок обработки
- не назначен ответственный
- несколько активных этапов
- некорректный временной интервал
- прочая проблема

Если обнаружено несколько нарушений, тип проблемы выбирать в порядке перечисленных условий.

В итоговый результат включить идентификатор отклика, вакансию, кандидата, текущий этап, ответственного рекрутера, количество нарушений и тип основной проблемы.

Результат отсортировать по количеству нарушений по убыванию, затем по дате получения отклика.

Задание 3. Анализ активности соискателей со скользящими показателями

Построить отчёт для анализа динамики активности соискателей по месяцам. Рассматривать соискателей, отправивших хотя бы один отклик за анализируемый период.

Для каждого соискателя и месяца предварительно определить количество отправленных откликов, количество уникальных вакансий, на которые были отправлены отклики, количество приглашений на интервью, количество полученных предложений о работе и количество отказов со стороны работодателей.

Внутри каждого соискателя месяцы необходимо упорядочить по возрастанию.

Для каждого месяца дополнительно рассчитать:
- количество отправленных откликов за предыдущий месяц
- количество откликов два месяца назад
- изменение количества откликов относительно предыдущего месяца
- среднее количество откликов за три предыдущих месяца, не включая текущий
- среднее количество откликов за текущий и три предыдущих месяца
- максимальное количество приглашений на интервью за текущий и три предыдущих месяца
- накопительное количество отправленных откликов с начала анализируемого периода
- накопительное количество полученных предложений о работе
- отклонение текущей активности от средней активности за три предыдущих месяца

Каждому месяцу соискателя присвоить категорию изменения активности:
- если предыдущего месяца нет, то начальный период
- если количество откликов увеличилось минимум на 50%, то резкий рост активности
- если количество откликов уменьшилось минимум на 50%, то резкое снижение активности
- если количество полученных предложений превышает 20% от количества отправленных откликов за месяц, то высокая результативность
- в остальных случаях стабильная активность

Месяцы без откликов между первым и последним месяцами активности соискателя должны присутствовать в отчёте с нулевыми показателями. При отсутствии предыдущих данных показатели сравнения должны принимать значение NULL.

Результат отсортировать по соискателю и месяцу.

Задание 4. Анализ изменения требований между версиями вакансий

Для каждой вакансии проанализировать изменение требований к навыкам между последовательными опубликованными версиями. Рассматривать только вакансии, имеющие не менее двух опубликованных версий.

Для каждой версии предварительно определить количество обязательных навыков, количество необязательных навыков, средний требуемый уровень владения навыками и количество полученных откликов.

После этого внутри каждой вакансии определить:
- количество обязательных навыков в предыдущей версии
- количество новых навыков по сравнению с предыдущей версией
- количество удалённых навыков
- количество навыков, для которых требуемый уровень был повышен
- изменение общего количества обязательных навыков
- изменение количества откликов относительно предыдущей версии
- среднее количество откликов по текущей и двум предыдущим версиям
- накопительное количество откликов по всем версиям вакансии

Каждой версии присвоить категорию изменения требований:
- если предыдущей версии нет, то первая версия
- если добавлено не менее трёх обязательных навыков, то ужесточение требований
- если удалено не менее трёх обязательных навыков, то смягчение требований
- если количество откликов уменьшилось минимум на 30%, то снижение интереса
- если количество откликов увеличилось минимум на 30%, то рост интереса
- в остальных случаях незначительные изменения

При сравнении навыков учитывать их идентификаторы, а при сравнении уровней числовые значения требуемого уровня. Условия классификации проверять в указанном порядке.

Результат отсортировать по компании, вакансии и номеру версии.

Задание 5. Комплексный рейтинг эффективности рекрутеров

Сформировать рейтинг рекрутеров по результативности работы с кандидатами. Рассматривать всех рекрутеров, имеющих зарегистрированные действия в истории подбора за анализируемый период, включая сотрудников, утративших полномочия.

Для каждого рекрутера необходимо независимо рассчитать несколько групп показателей.

По откликам:
- количество уникальных обработанных откликов
- количество просмотренных откликов
- количество отказов
- среднее время первого просмотра
- количество просроченных этапов

По интервью:
- количество проведённых интервью
- количество отменённых интервью
- количество интервью с положительным результатом
- среднюю продолжительность интервью

По предложениям:
- количество отправленных предложений
- количество принятых предложений
- количество отклонённых предложений
- среднее время от получения отклика до отправки предложения

Если один отклик проходил один этап несколько раз, при подсчёте уникальных откликов он должен учитываться только один раз. Повторные интервью должны учитываться как отдельные события.

Дополнительно рассчитать следующие показатели:
- interview_conversion = количество откликов, дошедших до интервью / количество обработанных откликов * 100
- offer_conversion = количество откликов, по которым отправлено предложение / количество откликов, дошедших до интервью * 100
- acceptance_rate = количество принятых предложений / количество предложений с окончательным решением кандидата * 100
- overdue_rate = количество просроченных этапов / количество всех этапов, за которые отвечал рекрутер * 100

Если данных для расчёта коэффициента недостаточно, его значение должно быть NULL.

После формирования показателей необходимо выполнить ранжирование.

Непрерывный рейтинг внутри компании.

Лучшим считать рекрутера:
1. с большим количеством принятых предложений
2. при равенстве с большей конверсией интервью в предложения
3. затем с меньшей долей просроченных этапов
4. затем с меньшим средним временем первого просмотра
5. затем с большим количеством обработанных откликов

Общий рейтинг по всем рекрутерам сервиса.

При ранжировании учитывать:
1. количество принятых предложений
2. процент принятия предложений
3. количество проведённых интервью
4. среднее время первого просмотра
5. количество просроченных этапов

Для непрерывного рейтинга использовать DENSE_RANK(). При ранжировании значения NULL должны располагаться после определённых значений.

В итоговый результат включить компанию, подразделение, рекрутера, рассчитанные показатели, рейтинг внутри компании и общий рейтинг.

Результат отсортировать по общему рейтингу по возрастанию.
